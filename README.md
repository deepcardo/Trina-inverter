# 光伏组件-逆变器及线缆匹配查询工具

一个用于光伏发电系统中组件、逆变器、并网箱及线缆选型匹配的在线查询工具。纯前端实现，无后端服务，部署于 GitHub Pages。

> 本文档是项目**事实类信息**（功能、命令、目录结构、数据维护、部署流程）的权威来源。
> 面向 AI 代理的开发规范与强制标准见 [CLAUDE.md](./CLAUDE.md)。

## 功能特性

- **区域选择**：支持全国省、市、区县三级联动选择，同步保持下拉框与搜索框状态一致
- **拼音搜索**：搜索框支持中文与拼音匹配，匹配分为「匹配」（精确首字母连续命中）与「模糊」两级，按 区县 > 城市 > 省份 优先级排序，最多展示 10 条
- **最近使用**：自动记录最近选择的地区（最多 10 条，存于 `localStorage`），支持单条删除与一键清空
- **容配比配置**：根据地区政策自动锁定容配比（1.0 / 1.1 / 1.2 倍三挡），选择地区后自动切换并高亮提示
- **组件系列**：支持四个系列：
  - `NEG21(715W)` — 715~720W
  - `NEG21(730W)` — 730~740W
  - `NEG22(780~785W)` — 780~785W
  - `NEG22(800W)` — 790~800W
- **湖南专项**：湖南省使用独立的中间挡位配置（`HUNAN_DB`），并限制组件系列；张家界市在专项覆盖区县另有专项调整（`ZHANGJIAJIE_DB`）
- **数量校验**：组件数量的合法范围随「组件系列 × 容配比 × 地区」动态计算，选择地区与系列后输入框实时显示可填范围，超出范围即提示错误
- **智能匹配**：根据输入条件自动查询并输出四类结果：
  - 逆变器配置方案
  - 逆变器交流铜线规格
  - 并网箱配置方案
  - 并网箱交流铝线规格
- **结果复制**：一键复制匹配结果到剪贴板
- **修改自动重查**：修改数量或组件系列后自动重新触发查询，无需重复点击

## 业务概念

| 概念 | 说明 |
|------|------|
| 容配比 | 直流侧组件容量与交流侧逆变器容量之比。本工具按地区政策锁定为 `1.2倍(正常)` / `1.1倍` / `1倍` 三挡，选中地区后不可手动修改 |
| 并网箱 | 逆变器交流侧并网成套设备，配置方案随逆变器组合一并输出 |
| 交流铜线 | 逆变器输出侧电缆，**强制使用铜线** `ZR-YJV-0.6/1kV` |
| 交流铝线 | 并网箱侧电缆，可使用铝线；超长时按 [技术规范](#技术规范) 升号 |
| 组件系列 | 组件功率档次（715 / 730 / 780~785 / 800W），决定可用的逆变器配置表 |
| 数量合法范围 | 由「地区 × 系列 × 容配比」在配置表中能命中的区间并集决定，页面提示与校验同源 |

更多业务术语见 [docs/glossary.md](./docs/glossary.md)。

## 快速开始

### 环境要求

- Node.js 18+（建议 20+）
- npm 9+

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

开发服务器启动于 `http://localhost:3000`（自动打开浏览器），支持热更新。

### 生产构建

```bash
npm run build
```

构建前会自动执行数据完整性校验（`npm run validate`），校验不通过则构建中止。产物输出到 `dist/`。

### 预览构建产物

```bash
npm run preview
```

## 使用说明

1. **选择地区**：通过顶部搜索框输入中文或拼音（如 `zhangjiajie` / `张家界`）快速定位，或使用省 / 市 / 区县三级下拉框逐级选择；已选地区会记录在「最近使用」中
2. **容配比锁定**：选定区县后，容配比按当地政策自动锁定（页面不可手动修改），并以高亮动画提示变化
3. **选择组件系列**：从下拉框选择组件系列；湖南地区仅开放 730W 系列
4. **输入组件数量**：输入框会根据当前「地区 + 系列 + 容配比」实时提示合法范围（占位符如 `10 ~ 120`），范围之外的输入会标红提示
5. **获取结果**：点击「智能匹配查询」按钮，或修改数量 / 系列后系统自动重新查询
6. **复制结果**：点击结果区的复制按钮，一键复制全部匹配结果

匹配结果包含：逆变器配置、交流铜线、并网箱配置、交流铝线，以及对应的施工规范提示。

### 输入校验规则

- **地区必选**：省 / 市 / 区县三级选齐后才触发匹配（搜索框选中会自动回填三级下拉框）
- **系列必选**：组件系列为空时不执行查询
- **数量必须为正整数**：非整数输入直接标红提示
- **数量范围动态**：合法范围 = 当前「地区专项表 ∪ 系列标准表」所有可命中区间的并集（min ~ max）。例如湖南 730 系列与全国标准表的范围不同，切换地区或系列后范围提示会立即刷新
- **查询时机**：点击查询按钮，或数量 / 系列发生变更时自动重查；地区变更会先清空旧结果

### 结果输出说明

| 输出项 | 内容 |
|--------|------|
| 逆变器配置 | 命中的逆变器组合与交流侧功率（`inv` / `box` 字段） |
| 交流铜线 | 逆变器侧铜线规格，按逆变器交流功率查 [技术规范](#技术规范) 对应阶梯 |
| 并网箱配置 | 命中的并网箱功率（`box` 字段）；该地区的并网箱类型备注（如「双刀闸」）单独显示在下方备注区 |
| 交流铝线 | 并网箱侧铝线规格，按逆变器累计功率匹配；功率超出建议表时提示「专项选型」 |

## 技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 前端 | 原生 HTML / CSS / JavaScript | 无框架依赖，无运行时 npm 依赖 |
| 构建 | Vite 6.x | `root: 'src'`，产物输出 `dist/`，`base: './'` 相对路径（适配 GitHub Pages 子路径） |
| 测试 | Vitest 4.x | 76 个单元测试，3 个测试文件 |
| 数据校验 | 自研校验脚本 | 110 项数据完整性检查 |
| 数据转换 | xlsx (SheetJS) | 仅用于 `npm run convert` 脚本，构建时不参与 |
| 拼音 | pinyin-pro 3.27.0 | 通过 jsDelivr CDN 引入（非 npm 依赖），见 `src/index.html` |
| 部署 | GitHub Actions + GitHub Pages | 推送 `main` 自动构建部署 |

## 数据维护

| 数据 | 维护方式 | 位置 | 来源 |
|------|---------|------|------|
| 区域容配比 | `npm run convert` 自动生成 | `src/public/js/data/region-data.js` | `全国并网箱&逆变器配置统计.xlsx` → 全国省市区列表 |
| 全国逆变器配置 | 手动编辑 | `src/public/js/data/inverters.js` | Excel 手动整理 |
| 湖南 / 张家界专项 | 手动编辑 | `src/public/js/data/hunan.js` | Excel 手动整理 |
| 线缆规格 | 手动编辑 | `src/public/js/data/cables.js` | Excel 手动整理 |

维护注意事项：

- `region-data.js` 是**生成产物**，不要直接手改；更新区域数据请改 Excel →
  同步更新 `scripts/convert-all.js` 顶部的 `DATA_VERSION` / `UPDATED_DATE` 常量 →
  执行 `npm run convert`（CI 会重新转换并与提交的生成物比对，不一致即部署失败）
- 手动修改 `inverters.js` / `hunan.js` / `cables.js` 时，请同步更新文件头部的版本信息与修改日期
- 修改数据后必须执行 `npm run test` 与 `npm run validate`，两者均通过方可提交

> 逆变器 / 线缆数据目前手动维护，未来可按需扩展 Excel 自动管线（见 [ADR-002](./docs/adrs/ADR-002-数据文件与代码分离策略.md)）。

## 部署

推送到 `main` 分支后，GitHub Actions（`.github/workflows/build-deploy.yml`）自动执行：

```
校验数据新鲜度（重新 convert Excel，与提交的 region-data.js 逐字节比对）
→ npm test → npm run build（内含 validate 数据校验）→ deploy-pages
```

- 任一环节失败（数据过期 / 测试不通过 / 校验不通过 / 构建失败），部署自动中止，线上不受影响
- 数据新鲜度检查依赖 convert 的**确定性输出**（生成文件头部不含时间戳）；
  改了 Excel 忘跑 `npm run convert` 时，此步直接失败
- 线上地址：GitHub Pages（仓库 Settings → Pages 查看）

发布前的强制检查项（副标题日期、推送规范等）见 [CLAUDE.md §强制标准](./CLAUDE.md#强制标准)。

## 技术规范

选型与施工规范（业务规则）：

- 逆变器输出线必须使用铜线 `ZR-YJV-0.6/1kV`
- 交流电缆长度 ≤ 50m：按标准表选取线径
- 50m < 长度 ≤ 100m：线径比规定大一号
- 100m < 长度 ≤ 150m：线径比规定大二号
- 长度 > 150m：需联系交付人员处理
- 铝线仅用于并网箱侧交流电缆，逆变器侧强制铜线

## 常见问题

**Q：为什么数量输入框提示的范围和别人的不一样？**
A：范围由「地区 × 组件系列 × 容配比」共同决定。湖南 / 张家界走专项表，与全国标准表范围不同；切换地区或系列后范围会实时刷新。

**Q：为什么湖南地区只能选 730W 系列？**
A：湖南地区业务上限制为 730W 系列，另有张家界专项覆盖区县，属既定业务规则，非缺陷。

**Q：`region-data.js` 能直接改吗？**
A：不能。它是 `npm run convert` 从 Excel 生成的产物，直接修改会在下次转换时被覆盖。正确流程是改根目录 Excel 后执行 `npm run convert`。

**Q：线缆功率超出建议表怎么办？**
A：超出建议表最大档（200kW）时工具会提示「超出建议表范围，需专项选型」，需联系交付人员处理，不得沿用最后一档。

**Q：改了数据文件但构建被拦截？**
A：`npm run build` 内置 110 项数据校验，测试或校验任一失败即中止。请按 [测试说明](#测试说明) 修复后重试。
