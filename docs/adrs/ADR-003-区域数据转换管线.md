# ADR-003: 区域数据转换管线（轻量版）

## 状态

已采纳，范围缩小 (2026-07-26)

## 背景

当前系统中仅区域容配比数据需要从 Excel 转换为 JS 数据文件：

1. 现有 `convert-excel.js` 已实现从 Excel 读取 → 输出 `region-data.js`
2. 逆变器配置表（DB、HUNAN_DB、ZHANGJIAJIE_DB）和线缆规格表（CABLE_THRESHOLDS）保持**手动维护**，暂不纳入自动化管线
3. 但现有脚本存在数据源指向不一致的问题：
   - `index.html` 中标注 `DATA_SOURCE = '全国容配比查询表0506.xlsx'`
   - `region-data.js` 中标注 `源文件: 全国容配比查询表0623.xlsx`
   - **实际权威来源**应为 `全国并网箱&逆变器配置统计.xlsx` → "全国省市区列表" sheet

## 决策

仅处理区域容配比数据的转换，与现有 `convert-excel.js` 功能对齐，但做如下改进：

### 数据源统一

| 项目 | 当前值（有误） | 修正后 |
|------|--------------|--------|
| 源文件 | `全国容配比查询表0506.xlsx` | `全国并网箱&逆变器配置统计.xlsx` |
| Sheet | 容配比查询 / Sheet1 | **全国省市区列表** |
| 输出 | `region-data.js` | `src/js/data/region-data.js` |

### 管线流程

```
npm run convert
    │
    └── scripts/convert-all.js
            │
            ├── 读取: data/全国并网箱&逆变器配置统计.xlsx → Sheet: "全国省市区列表"
            │
            └── 输出: src/js/data/region-data.js
```

### 不纳入管线的部分（保持手动维护）

- 逆变器配置表（DB）—— 直接在 `src/js/data/inverters.js` 中编辑
- 湖南/张家界专项配置（HUNAN_DB / ZHANGJIAJIE_DB）—— 直接在 `src/js/data/hunan.js` 中编辑
- 线缆规格表（CABLE_THRESHOLDS）—— 直接在 `src/js/data/cables.js` 中编辑

## 理由

- **现状已有 `convert-excel.js`**，功能基本满足，只需修正数据源指向
- **DB 数据格式复杂**（4个系列×3种容配比×多挡位），需要从 Excel 的特定格式解析，当前手动维护更可控
- **DB 更新频率低**（按需不定期），手动编辑工作量可接受
- **渐进式原则**：先把区域数据的管线跑通，未来需要时再扩展

## 被拒绝的方案

1. **全部数据自动化**：逆变器/线缆数据格式复杂，当前阶段优先级不高
2. **设计 Excel 模板标准**：需要与业务方协调，暂时不推动

## 影响

- `convert-excel.js` 需要更新数据源指向（文件名 + Sheet 名）
- `index.html` 中的 `DATA_SOURCE` 注释同步修正
- 区域数据更新流程变为：**更新 Excel → ` npm run convert` → `npm run build` → 部署**
- 逆变器/线缆数据的"单一数据源"靠维护规范来保证
