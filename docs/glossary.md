# 系统术语表 (Glossary)

## 通用术语

| 术语 | 缩写 | 定义 |
|------|------|------|
| 光伏 | PV | 太阳能光伏发电系统 |
| 组件 | Module/Panel | 太阳能光伏板，将光能转换为电能的基本单元 |
| 逆变器 | Inverter | 将直流电(DC)转换为交流电(AC)的设备 |
| 并网箱 | Combiner Box | 用于汇流光伏组串并进行并网保护的配电箱 |

## 组件系列

| 术语 | 定义 |
|------|------|
| NEG21(715W) | 715W 功率档的 NEG21 系列光伏组件 |
| NEG21(730W) | 730W 功率档的 NEG21 系列光伏组件 |
| NEG22(780~785W) | 780~785W 功率档的 NEG22 系列光伏组件 |
| NEG22(800W) | 800W 功率档的 NEG22 系列光伏组件 |

## 配置参数

| 术语 | 定义 |
|------|------|
| 容配比 | 组件总功率与逆变器额定功率的比值。如 1.2 倍表示组件功率为逆变器功率的 1.2 倍 |
| 不超配(1倍) | 容配比为 1:1，组件功率等于逆变器额定功率 |
| 轻度超配(1.1倍) | 容配比为 1.1:1，组件功率略高于逆变器额定功率 |
| 正常超配(1.2倍) | 容配比为 1.2:1，组件功率高于逆变器额定功率（行业通用做法） |
| 组件数量 | 单个光伏系统中安装的光伏板数量（片） |
| 逆变器组合 | 推荐使用的逆变器型号及台数（如 "50+50" 表示两台 50kW 逆变器） |
| 并网箱功率 | 搭配使用的并网箱额定功率（如 100kW） |

## 线缆规格

| 术语 | 定义 |
|------|------|
| 交流铜线 | 铜芯交流电力电缆，用于逆变器到并网箱的连接 |
| 交流铝线 | 铝芯交流电力电缆，用于总输出端到电网的连接 |
| 单相 | 单相交流电（通常用于 8kW/10kW 小功率系统） |
| 三相 | 三相交流电（用于中大功率系统） |

## 业务对象

| 术语 | 定义 |
|------|------|
| 区域容配比 | 根据不同地区的电网接入政策，规定的容配比限制（如"不超配1"含义为容配比≤1） |
| 并网箱类型 | 根据不同功率等级和地区要求，配置的并网箱型号 |
| 全国标准表 | 适用于全国绝大多数地区的通用逆变器配置表 |
| 湖南专用配置 | 湖南省特有的中间挡位配置，覆盖标准表未包含的组件数量范围（55-76片） |
| 张家界专项配置 | 张家界市在湖南配置基础上的进一步调整 |

## 系统模块

| 术语 | 定义 |
|------|------|
| REGION_DB | 区域容配比数据库，存储全国各省市县对应的容配比限制 |
| DB | 逆变器配置表，按组件系列×容配比分组的有序挡位数组 |
| HUNAN_DB | 湖南省专用逆变器配置表 |
| ZHANGJIAJIE_DB | 张家界市专项逆变器配置表 |
| CABLE_THRESHOLDS | 线缆规格表，按功率阶梯映射铜线和铝线规格 |
| 三级联动 | 省份→城市→区县的三级级联下拉选择器 |
| 双轨道搜索 | 同时支持中文子串匹配和拼音匹配的搜索机制 |

## 系统架构

| 术语 | 定义 |
|------|------|
| 数据管线 | 从 Excel 源文件到 JS 数据文件的一键转换流程 |
| 数据验证 | 在构建前自动检查数据完整性和一致性的脚本 |
| Vite | 前端构建工具，提供开发服务器和打包功能 |
| GitHub Actions | CI/CD 自动化流水线，用于自动构建和部署 |
| gh-pages | GitHub Pages 的部署工具/分支 |
